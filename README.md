# WellGuardian scope brief

A one-page questionnaire for Sabine (WellGuardian Health & Advocacy) to lock the project scope. No account needed.

- Answers autosave in her browser (localStorage).
- "Send my answers" posts them to Saif's inbox through FormSubmit.co.
- Follow-up questions: after reviewing her answers, edit `followups.json` (`round`, `summary`, `understood`, `followups[{id, question, why, options}]`) and push to `main`. The page shows them as round two at the same link.

Hosted with GitHub Pages from `main`.
